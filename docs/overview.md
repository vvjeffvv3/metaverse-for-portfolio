# 프로젝트 개요

PLAYDATA METAVERSE는 학습과 소통을 위한 팀 메타버스 프로젝트입니다. 이 포트폴리오는 vvjeffvv3가 작성한 PR와 관련 구현 경험을 중심으로 정리합니다.

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| 원본 | [팀 저장소](https://github.com/playdatametaverse/playdatametaverse) |
| 프로젝트 기간 | 작성 예정 |
| 팀 구성과 역할 | 작성 예정 |
| 개인 담당 범위 | 대표 PR의 변경 파일 확인 후 확정 |
| 공개 시연 주소 | 준비 예정 |

## 주요 이용 흐름

입장과 이동, 학습 콘텐츠, 소통 기능, 이벤트와 게임 콘텐츠를 중심으로 실제 화면과 사용 순서를 정리할 예정입니다.

## 개인 작업을 설명할 영역

대표 PR 제목을 기준으로 이벤트 운영과 게임 콘텐츠, 입장과 이동 경험 개선, 게시판 조회 분리와 Outbox 기록을 사례 후보로 선정했습니다. 구체적인 구현 방식과 결과는 각 사례 문서에서 변경 내용을 확인한 뒤 작성합니다.

## 추가할 설명

- 사용자와 서비스가 해결하려는 문제
- 팀에서 맡은 범위와 협업 방식
- 핵심 화면 3~5장과 기능 설명
- 실제로 사용한 기술과 선택 이유
